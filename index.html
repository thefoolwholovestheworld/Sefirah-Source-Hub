Créer une source pour Sefirah en 4 étapes

Une « source » = un petit fichier .lua qui apprend à Sefirah à lire un site (recherche, fiche, chapitres). Pas besoin de savoir coder pour une première version.

1Choisir le site
Colle l'adresse du site et dis si c'est un roman ou un manga. L'outil devine les réglages.
2Vérifier les réglages
3 à 5 champs, chacun avec une aide « où le trouver ». Tout est pré-rempli quand c'est possible.
3Tester
Un clic lance 10 contrôles : accueil, recherche, fiche, chapitres, lecture.
4Installer
Télécharge le fichier, copie-le dans le plugin, redémarre KOReader.
Avant de commencer
  • Si le site est protégé (Cloudflare, CAPTCHA), l'outil le dira : il ne le contourne pas.
  • Sans proxy, la plupart des sites sont illisibles depuis le navigateur : voir Tester › Proxy (2 minutes, gratuit).
  • Rien n'est envoyé nulle part : tes sources restent dans ton navigateur (« Mes sources »).

① Le site② Les réglages③ Générer④ Tester et installer

1Le site à ajouter

Colle l'adresse de la page d'accueil, puis clique « Analyser le site ». Si ça échoue, passe à l'étape 2 : tu peux tout remplir à la main.

2Les réglages

Comment trouver ces infos ? (30 secondes)

Ouvre le site dans ton navigateur. Pour chaque champ, la réponse se voit dans la barre d'adresse : ouvre une œuvre, puis un chapitre, et note ce qui ressemble à /manga/ ou /chapter/. Pour la classe CSS : clic droit sur le texte du chapitre › Inspecter, repère class="…".

Fais une recherche sur le site, copie l'adresse, puis remplace le mot cherché par {q} (et le numéro de page par {page}). Pas de page de recherche à adresse fixe ? Laisse vide : Sefirah cherchera alors le titre parmi les œuvres de la page d'accueil du site.

Nouveau ? Commence par l'onglet Démarrer.

Installer une source dans Sefirah

  1. Télécharge le fichier .lua (Catalogue ou Mes sources).
  2. Copie-le dans koreader/plugins/sefirah.koplugin/extensions/ (le nom du fichier = l'identifiant de la source).
  3. Ajoute la ligne « metas » affichée sous le code dans core/extmgr.lua, dans la table metas.
  4. Redémarre KOReader, ouvre Sefirah › Sources, installe la source.

Contrat d'une source

Un fichier Lua retourne une table ext : popularNovels(page, options) et searchNovels(term, page) → {novels={{name,path,cover}}} ; parseNovelMeta(path) ; parseNovel(path) → fiche + chapters={{name,path,chapter_number}} ; parseChapter(path) → HTML ; pour un manga : ext.type="manga" et parseChapterImages(path) → {images={…}, headers={…}}. Référence : extensions/mangapill.lua.

Limites

Le navigateur seul ne peut pas lire la plupart des sites (CORS) : il faut le proxy. Les sites protégés par Cloudflare / CAPTCHA sont signalés comme bloqués, jamais contournés. Les sources du catalogue sont marquées « non vérifié » tant qu'un test réel n'a pas été fait. Licence : les fichiers dérivés de Mythos restent sous GPL-3.0.
